## Important: corresponding-source publication still needs verification

The binaries for Windows and Linux already exist in V0.9, but at the time this note was prepared the public `archipelago-prototype` branch had older files (including a V0.8.4 client version) and lacked the new `ap_collectibles_radar.h`. The V0.9 Windows/Linux complete corresponding source has **not** been verified as publicly available. A GPL notice, an upstream source link, or only a patch/diff is not a substitute.

To fulfill redistribution requirements, publish and make conveniently downloadable the full, exact sources from which each V0.9 executable was built, including:

1. Windows V0.9 application and Archipelago code, the new radar/shop/stats/exorcism modules, generated or embedded source that is required to rebuild, and build instructions.
2. The Linux V0.9-specific networking/audio/CMake changes and all other modified Linux code needed to rebuild that package.
3. The APWorld source version corresponding to the published `.apworld` if covered by the chosen license, plus relevant build/package instructions.
4. All required GPL and third-party attribution/license notices. Check original authored artwork and mod assets separately.
5. A **permanent, version-specific source tag or source archive** for each platform; link it visibly from this release page and keep it accessible for as long as these binaries remain distributed.

**Do not publish** `default.xex`, `default.xexp`, proprietary game files, actual saved games, local backups, credentials, or other private data. Reproduce required open-source components from properly licensed sources and documented build instructions.

GPLv3 §6(d) permits using a different server for corresponding source if equivalent access and clear directions are provided. See the [official GNU GPL FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#SourceAndBinaryOnDifferentSites).
